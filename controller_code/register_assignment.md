### 现有资源
#### TABLE
超大数组，可存储float64

##### 用法
1）TABLE 指令读写数据
TABLE(0) = 10 'TABLE(0)赋值 10
TABLE(10,100,200,300) '批量赋值，TABLE(10)赋值 100，TABLE(11)赋值 200，TABLE(12)赋值 300

打印数据
PRINT TABLESTRING(100,3) '字符串格式打印数据，转换为ASCII 码（100，101，102）

'''
PRINT TSIZE '打印出控制器 TABLE 大小 
TSIZE=10000 '设置 TABLE 的大小，不能超过控制器TABLE 最大SIZE 
'''

#### FLASH
读写次数有限，建议写不常改的参数，需要对具体的块进行操作，需要注意块的大小
写入：
FLASH_WRITE 1，VAR，ARRAY1，ARRAY2
读取：
FLASH_READ 1，VAR，ARRAY1，ARRAY2 '读取次序与写入次序一致

#### VR
具有掉电存储功能，但是容量较小，通常用于紧急存储参数
VR：32位浮点
VR_INT：整型
VRSTRING：字符串

写入：
VR(0) = 10.58
VRSTRING(0,4) = "abc"

读取：
aaa = VR(0)
PRINT VRSTRING(0,4)

#### MODBUS
符合MODBUS通讯协议，掉电不保存
MODBUS在给定的存储空间下，可以以不同的数据进行存储，以16位INT作为一个单元，不同模式之间的地址要注意区分。具体占用方式见手册，为了方便起见，只用REG形式，即16位INT类型的数进行存储。
MODBUS_BIT（位寄存器）0~7999
MODBUS_REG（位寄存器）0~7999

### 资源分配
#### TABLE
0-299，机器人结构参数
300-349，单轴运动指令数据
  - 每条指令 7 个 float：`cmd_id, j1..j5, speed`；cmd_id 仅支持 1=MOVE（相对运动）；第 7 字段为速度（mm/s，上限 20，控制器侧限幅 MAX_MANUAL_SPEED）
350-399，点动指令数据
  - 每条指令 7 个 float：`cmd_id, x, y, z, phi, theta, speed`；cmd_id 支持 1=MOVE（相对直线）、2=MOVEABS（绝对直线）；第 7 字段为速度（mm/s，上限 20）
400-419，力传感器适配与法向力控参数（详见 `global_config.bas` 的 `FORCE_CFG_*` 偏移）
  - 400=硬件适配启用，401=数据有效，402=单调递增采样序号，403-408=六轴原始值
  - 409=标度，410=零位，411=滤波系数，412-413=PI 增益，414=过力阈值
  - 415=修正量硬限幅，416=修正速度限幅，417=接触判定周期数，418=Z 修正方向，419=断流周期阈值
  - 第一阶段启用采集、PI 增益保持 0；409 初始为 5kgf/32768 的理论比例，410 初始为 0，均需实测校准
  - 硬件层在新采样时更新采样序号，禁止在周期中断中执行阻塞式通信；AIN 与 PDO 路径均以 CH1 CycleCounter 判断新数据
420-427，EL3702 默认 n=1 输入 PDO 原始字节，每个 TABLE 保存 1 字节
  - 节点 6 为 EK1100，节点 7 为 EL3702，Fz 接 EL3702 CH1；420-421=CH1 CycleCounter，422-423=CH1 有符号 16 位采样值，424-427=CH2 对应数据
  - 标准 AIN 可用时优先使用：AIN(32)=CH1 CycleCounter，AIN(33)=CH1 模拟量原始码；按有符号 INT16 恢复正负值，420-427 不参与换算；PDO 路径按小端序解析
428-449、452-999，预留（450、451 已分配给末端工具）
450，公转电机目标转速，单位 rpm；非零，绝对值不超过 2000，负数表示反转
451，自转电机目标转速，单位 rpm；非零，绝对值不超过 2000，负数表示反转
  - 公转为 EtherCAT 第 6 个从站、轴号 5，ATYPE=66、DRIVE_PROFILE=20，通过 DAC 调速，DAC=0 停止
  - EK1100 与 EL3702 分别为节点 6、7，均不占用电机轴号；总线期望设备数为 8，电机轴数仍为 6
  - EtherCAT 速度模式的 DAC 单位为脉冲数/秒；23 位编码器直驱且无额外电子齿轮缩放时，每转 8388608 脉冲
  - TOOL_REV_PULSES_PER_REV=8388608，TOOL_DAC_PER_RPM=每转脉冲数/60；例如 10rpm 对应 DAC≈1398101.33
  - 自转使用 ZMC406-V2 高速 OUT0 硬件 PWM 输出脉冲，OUT4 为方向，OUT5 为高有效使能；OUT0 与 AXIS6 复用，初始化必须设置 ATYPE(6)=0 释放普通输出，ATYPE=3 为编码器轴而非虚拟轴
  - 每转 3200 脉冲，PWM 频率(Hz)=|rpm|×3200/60；10rpm 对应 533.33Hz，2000rpm 对应 106666.67Hz，低于 OUT0 的 400kHz 上限
  - 正转速 OUT4=ON，负转速 OUT4=OFF，PWM 占空比为 0.5；启动时先使能并设置方向，再输出 PWM
  - 停止时先设 PWM_DUTY(0)=0，再关闭 OUT0、OUT4 和 OUT5；恒速直接启停，不使用 VMOVE，不带加减速规划
1000-9999，轨迹数据
21000-29449，状态监控环形区（header 2 + 384 帧 × 22 通道，ctrl_mgr.bas 每 10 个伺服周期在一个周期内用一条 TABLE 指令采集完整帧，1kHz 总线 → 100Hz，上位机 0.1s 批量读取约 10 帧）
  - 384 帧在 100Hz 下覆盖 3.84s
  - 要求 TSIZE ≥ 29450（main.bas 初始化最前面已设置 TSIZE = 34000）
  - header：TABLE(21000)=frame_counter，TABLE(21001)=write_index（下一帧写入位置）
  - 每帧布局：[0-4] dL(um) / [5-9] 扭矩(‰) / [10-14] 末端 x,y,z,phi,theta / [15] ee_valid / [16-21] 六轴力/力矩原始值
  - 不上传编码器及滤波力、目标力、Z 修正量、力控模式、传感器状态等派生状态；29450-33289 保留

轨迹数据区（1000-9999）布局：
- 10 个指令组，每组 100 条指令，每条 7 个数（一组占 700 个 TABLE 位置）
- 每条指令：`cmd_id, p1, p2, p3, p4, p5, p7`
- 普通运动：1=MOVE、2=MOVEABS、9=MOVE_PT、10=MOVE_PTABS、20=MOVE_DELAY；PT 第 7 字段为 ticks，DELAY 第 7 字段为毫秒
- 30=FORCE_CFG：`[30, mode, target_N, contact_N, ramp_N_s, max_adjust_um, reserved]`；mode=1 接触搜索，mode=2 恒力保持
- 31=FORCE_OFF：结束当前力控段；0=CMD_NONE：结束整条轨迹
- 第 g 组起始地址 = 1000 + g × 700；组状态寄存器为 MODBUS_REG(50 + g)
- 普通 TRAJ 不接受 FORCE_CFG/FORCE_OFF；完整混合加工文件使用 EVENT_CTRL，由 `CTRL_TRACE_STEP()` 作为唯一 TABLE 消费者
- CTRL 普通段支持全部普通运动指令；FORCE_CFG 后等待普通运动完成，力控段只接受 PT/PTABS、FORCE_CFG、FORCE_OFF
- 力控段内部统一转换为 ticks=1 的绝对 PT 目标 `nominal_pos + adj_pos`；CMD_NONE 前必须 FORCE_OFF，最后等待所有轴 IDLE 才上报完成
- 上位机发送器自动附加 CMD_NONE，.dat 文件不需要手工填写结束记录

#### MODEBUS_REG
0-49，系统状态指示
50-69，轨迹数据状态
70-79，点动数据状态
80-89，单轴数据状态
90-99，事件序列(每个位置代表一个等级)
  - 11=公转启动/调速，12=公转停止，13=自转启动，14=自转停止；均由 Level 2 (REG 92) 下发
  - 工具事件独立于机器人 FSM，不改变 system_state、motion_mode、active_task
  - 任一工具处于命令 ON 时拒绝 HOME；Homing/Error/Estop 状态禁止启动工具
  - 普通 STOP 仅停止机器人轴 0-4，不停止工具；ESTOP 停止全部工具并清除工具命令状态
  - 工具相关错误码：1013=工具运行中禁止回零，1014=工具转速非法
